# LifeQueue - Task Management Application

A simple and intuitive productivity application that helps you manage your tasks in an organized queue system.

## Features

- **Two Queue System**: Separate queues for daily and weekly tasks
- **Drag-and-Drop**: Easily reorder tasks by dragging them to your preferred position
- **Queue-Based Approach**: New tasks are added to the end of the queue, helping you finish what you started
- **Task Management**: Mark tasks as complete or delete them
- **Persistent Storage**: Tasks are saved locally in your browser
- **Clean Interface**: Modern, responsive design that works on desktop and mobile

## How to Use

1. Open `index.html` in your web browser
2. Add tasks to either the "Day Queue" or "Week Queue" using the input fields
3. Press Enter or click "Add" to add a task (it will be added to the end of the queue)
4. Drag and drop tasks to reorder them within their queue
5. Click the checkmark (✓) to mark tasks as complete
6. Click the X to delete tasks

## Philosophy

LifeQueue follows a simple productivity principle: add new tasks to the end of your queue so you can focus on completing what you've already started. This helps maintain momentum and ensures you finish tasks before taking on new ones.

## Technology

Built with vanilla HTML, CSS, and JavaScript - no dependencies required!
